# 탈락 후보 (2026-10-24)

챔피언으로 확정한 `art/champion/` 외에 비교했던 후보를 기록으로 남긴다. 앞선 6가지 스타일 후보와 SNS 게임 화면 6장은 `art/style-candidates/`, `art/sns-game-test/`에 있다.

## 탈락 사유
- `vertical-s1-style/`(6장): 굵은 3D 만화 스타일을 세로로 만든 것. 완성도는 높지만 Supercell·Playrix 같은 일반 캐주얼 게임으로 읽혀 "밈 게임" 느낌이 약했다.
- `leaderboard-variants/`(8장): 글로벌과 친구 랭킹을 한 화면에 담는 4가지 변형(a~d, 각 2장). 같은 이유로 탈락했고, 랭킹 화면은 챔피언 스타일로 새로 만든다.
- `meme-style-alternates/`(4장): 챔피언으로 뽑은 밈 스타일의 다른 생성본. 같은 지시에서 나왔고 표정·구도가 덜 강해 선택하지 않았다.

모든 화면 속 닉네임·점수·문구는 가상이다. 글자가 깨진 닉네임이 일부 있다.
