# 데일리 후킹 이미지 챔피언 (확정 2026-10-24)

`friday-5pm-tense.jpg`(1200×630)를 데일리 후킹 이미지의 챔피언으로 확정한다. 결정자: Simon님. 앞으로 게임 후보의 후킹 이미지도 같은 공식으로 만든다.

## 확정 사유 (Simon님 말씀 그대로)
> 공식은 밈의 메시지를 가장 직관적, 유머러스, 후킹하게 잘 표현하기 때문입니다.

## 공식 (이 그림에서 뽑은 것)
1. **주인공의 극단 클로즈업 표정**: 식은땀을 흘리며 굳은 얼굴이 화면의 약 40%를 차지한다. 감정이 가장 먼저 읽힌다.
2. **게임 핵심 오브젝트를 크게**: 눌러야 할 빨간 버튼이 앞쪽에 있어 "무엇을 하는 게임인지"가 보인다.
3. **뒤에서 닥치는 시간·위협**: 달려오는 보스와 5시 직전의 시계. 긴장이 만들어진다.
4. **그 밈의 세계**: 금요일 5시의 사무실.
5. **따뜻한 고대비 빛, 스피드 라인, 스파크**: 정지 그림인데도 움직임이 느껴진다.
6. **글자 없음**: 제목과 실행 버튼은 텔레그램 카드가 얹는다. 크기는 1200×630.

## 쓰는 방법
- 게임 카드마다 세 줄(핵심 오브젝트, 위협, 밈의 세계)만 정하면 같은 공식으로 만든다.
- 주인공은 매일 같은 마스코트(주황 캐릭터)로 두고 세계와 소품만 바꾼다.
- 올리기 전 순서는 에셋 가이드(`docs/ASSET_GUIDE.md` 8절)를 따른다.

## 한계
- 이 그림의 보스와 주인공 넥타이는 고정 설계서 세트와 다르다. 세트가 확정되면 같은 공식으로 다시 만든다.
- 모든 닉네임·글자는 없고, 기존 밈·캐릭터·실존 인물은 쓰지 않았다.
