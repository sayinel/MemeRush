# 챔피언 스타일 (확정 2026-10-24)

`art/champion/`의 4장을 챔피언 이미지로 확정했고, 게임 화면 스타일은 이 이미지를 기준으로 만든다. 결정자: Simon님.

## 확정 사유
- 앞선 후보(`art/style-candidates`, `art/sns-game-test`)는 완성도는 높았지만 일반 캐주얼 게임 느낌이 강해 "밈 게임"으로 읽히지 않았다.
- 이 4장은 같은 완성도(굵은 윤곽, 윤기 있는 버튼, 밝은 하늘)를 유지하면서 밈의 문법을 더했다: 반응 짤처럼 과장한 표정(우쭐함, 억울함, 식은땀), 두꺼운 흰 테두리 스티커, 굵은 자막 문구, 엉뚱한 소품(폭탄 위의 오리).
- 이 문법은 [밈과 게임의 결합 설계](../../docs/MEME_GAME_DESIGN.md)의 결말 자리(성공 컷·실패 컷 두 줄 자막)와 맞는다.

## 구성
- `1_play`: 플레이 화면. 타이머를 지켜보는 긴장감과 STOP 버튼.
- `2_champion`: 챔피언 결과(오차 0.01초). 우쭐한 표정, 웃는 트로피.
- `3_close-miss`: 아쉬운 결과(오차 0.84초). 눈물이 맺힌 확대 얼굴.
- `4_share-card`: 공유 카드. 월드 순위·친구 순위 배지, QR 자리.

## 실제 에셋을 만들 때 (중요)
- 이 4장은 방향을 보여 주는 시안이다. 시안 안의 자막과 기록 숫자는 그림에 구워져 있다.
- 실제 게임·영상 에셋은 문구와 숫자 없는 배경으로 만든다. 밈 문구와 기록은 코드가 위아래 두 줄로 얹는다(MEME_GAME_DESIGN 4절의 `win`/`lose`).
- 영상 배경(성공·실패)은 밈과 무관한 공용 이미지로 만들고, 위아래 25%는 자막 자리로 비운다.

## 지킬 것
- 시안의 닉네임·점수·문구는 모두 가상이다.
- 기존 밈 이미지·캐릭터·실존 인물·상표는 쓰지 않았다.
- 시안의 영어 문구("DON'T. BLINK." 등)는 예시이고 실제 밈 카드가 정한 문구를 쓴다.
