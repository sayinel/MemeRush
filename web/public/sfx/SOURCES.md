# 소리 출처와 이용 조건 (2026-10-31)

- `01_go`: OpenGameArt "voiceover pack: fighter" 계열의 `Audio_ready.ogg`. 검색을 CC0 라이선스 필터로 걸어 받았고, 개별 페이지의 라이선스 문구는 아직 한 건씩 대조하지 않았다(미확인).
- `08_lose`: OpenGameArt "voiceover pack: 40 lines"의 `Male_time_over.ogg`. 위와 같은 조건(CC0 필터, 개별 대조 미확인).
- `02_tap`, `03_nice`, `05_early`, `06_late`, `07_win`: 핏이 코드(numpy 합성)로 직접 만든 소리라 외부 권리가 없다.
- `04_perfect`, `bgm/5.mp3`: Google Vertex AI의 Lyria(`lyria-002`)로 생성한 소리다. 생성물의 이용은 구글 클라우드 이용 약관을 따르고, 생성 음원에는 워터마크(SynthID)가 들어갈 수 있다.
- 모든 파일은 -16 LUFS로 음량을 맞추고 mp3로 변환했다.

개별 음원의 라이선스를 한 건씩 대조하면 이 표의 "미확인"을 지운다.
