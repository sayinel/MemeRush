# 효과음 폴더 (역할별)

폴더 이름의 번호가 효과음 역할이고, 각 폴더의 `pick.mp3` 한 개를 게임이 읽습니다(없으면 코드로 만든 합성음이 나옵니다). 용량은 파일당 100KB 이하를 권장합니다.

- 01_go: 라운드 시작
- 02_tap: 빨간 버튼 누름(판마다 한 음씩 올라감)
- 03_nice: 좋은 기록(근접)
- 04_perfect: 완벽
- 05_early: 너무 일찍 눌러 보스에게 걸림
- 06_late: 너무 늦게
- 07_win: 최종 성공
- 08_lose: 최종 실패
- bgm/5.mp3: 게임 중에만 나오는 배경음악 반복 곡(기본 곡 번호는 `src/game/sfx.ts`의 `DEFAULT_BGM`)

기본값은 효과음 켜짐, 배경음악 꺼짐이고 화면의 버튼 두 개(🔊 효과음, 🎵 음악)로 따로 켜고 끕니다(선택은 기기에 저장). 주소 끝에 `?sound=1`을 붙이면 시험 모드입니다(음악 기본 켜짐, 진동, 후보 목록이 있을 때 왼쪽 소리 조합 패널).
라이선스: 직접 만든 것, CC0, 또는 상업 사용 가능한 것만 넣고 출처를 [SOURCES.md](SOURCES.md)에 한 줄씩 적습니다.
