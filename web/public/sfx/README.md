# 효과음 폴더 (역할별)

폴더 이름의 번호가 효과음 역할입니다. 각 폴더에 mp3 한 개를 넣으세요(파일 이름은 자유, 폴더에 파일이 여러 개면 가나다 순 첫 번째를 씁니다).
용량은 파일당 100KB 이하를 권장합니다(모바일 첫 접속이 느려지지 않도록).

- 01_go: 라운드 시작 (0.3~0.8초)
- 02_tap: 빨간 버튼 누름 (타격감, 0.3~1초)
- 03_nice: 좋은 기록(근접) (반짝임, 0.5~1.2초)
- 04_perfect: 완벽 (크게 터지는 느낌, 1~2.5초)
- 05_early: 너무 일찍 눌러 보스에게 걸림 (경보/쾅, 0.7~1.5초)
- 06_late: 너무 늦게 (실패 슬픈 느낌, 1~2초)
- 07_win: 최종 성공 (팡파르, 1.5~3초)
- 08_lose: 최종 실패 (어두운 붐, 1.5~3초)

파일이 없는 폴더는 지금처럼 코드로 만든 소리를 씁니다. 라이선스: 직접 만든 것, CC0, 또는 상업 사용 가능한 것만 넣고 출처를 이 폴더 `SOURCES.md`에 한 줄씩 적어 주세요.
