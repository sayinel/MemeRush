
## 온라인 시연 모드 (ADMIN_DEMO=1)
배포 환경(Vercel)에 `ADMIN_DEMO=1`을 넣으면 `/admin`이 열린다. 샘플 모드로 고정되고(파이프라인 파일을 읽지 않음), 실제 명령(execFile)은 403으로 막힌다. 로컬은 지금처럼 `ADMIN_LOCAL=1`. 둘 다 없으면 404. 시연 뒤에는 변수를 지운다.

### 온라인 시연 상태는 쿠키에 둔다 (라이브 QA 10/24)
Vercel은 서버가 여러 대로 나뉘어 메모리 상태가 요청마다 달라져 화면이 3~4단계로 되돌아갔다. `ADMIN_DEMO=1`일 때는 시연 진행 상태를 쿠키 `adm_sim`(약 1KB, httpOnly, 6시간)에 담아 매 요청마다 되살린다. 두 서버를 번갈아 호출하며 전체 흐름이 이어지는 것을 확인했다.
