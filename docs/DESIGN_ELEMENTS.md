## 2. 캐릭터 규격(바이블)
- 공통: 흰 스티커 테두리 + 갈색 안쪽 윤곽, 윤기 나는 만화 스타일, 글자·숫자 없음, 실존 인물·기존 밈 캐릭터·상표 없음
- 주인공: 둥근 서양배형 주황 블롭, 큰 흰 눈, 분홍 볼, 짧은 빨간 넥타이, 짧은 팔다리
- 보스: 갈색 둥근 달걀형 대머리, 짙은 눈썹, 안경 없음, 짙은 회색 정장 + 흰 셔츠 + 회색 넥타이
- 외계인: 올리브갈색 달걀형 주름 머리, 찌푸린 눈썹, 회청색 후드 높은 칼라 망토와 어깨 장갑
- 노점상: 주황 블롭, 베이지 종이 모자, 지저분한 회색 앞치마, 넥타이 없음
- 표정 시트 9종 구성: 무표정/놀람/선글라스(우쭐)/눈물/식은땀/폭소/손으로 얼굴 가림/반짝눈 주먹/졸음. 조연은 같은 틀에서 화남·웃음·진지·놀람·비웃음·실망·환호·지침 등으로 바꿨다

## 3. 비어 있던 것과 이번에 채운 것
- 채움: 외계인·노점상 표정 시트(위)
- 아직 없음: 보스 표정 시트(생성 시도 중 거절이 반복되어 표현을 바꿔 재시도 중), 조연 개별 스프라이트(시트를 컷별로 잘라 쓸 수 있음. 같은 캔버스·발 기준점 규칙은 `SIMON_REQUESTS.md` 공통 규칙)
- 별도 요청 그림(`SIMON_REQUESTS.md` 1·2절)은 PR #32 대응 작업으로 생성 중이며 파일은 `web/public/game/` 형식에 맞춰 올린다
