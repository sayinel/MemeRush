# 운영 정책 (노출 시간·알림)

> 2026-10-24 결정: 해커톤 중에는 구현하지 않고 정책으로만 기록한다. 해커톤 시연이 우선이다.

## 1. 게임 오픈 시각
- 현재 정책(권장안, 미확정): 사용자 현지 시간 자정(00:00)에 "오늘의 게임"이 열린다. Wordle·NYT Connections의 방식이다.
- 랭킹은 날짜 키(예: 2026-10-25)를 공유해 글로벌 합산한다.
- 근거: 목표가 글로벌 사용자라 한국 시각 하나로 정하지 않는다.

## 2. 알림·SNS 게시
- 알림은 지역별 현지 19~21시에 보낸다(일반 앱 푸시 통계에서 저녁 조회가 아침의 약 2배. 숏게임 전용 수치는 확인하지 못했다).
- 공식 계정 게시 시각을 하나로 정해야 하면 후보는 20:00 ET(한국 다음 날 오전 9시)다.
- 게임 종료 화면의 "내일의 게임" 카드 아래에 텔레그램 알림 받기 링크를 둔다.

## 3. 철회한 안
- 22:00 KST 단일 발행: 글로벌 목표와 맞지 않아 철회했다.

## 4. 다시 판단할 신호
- 출시 후 1~2주 접속 시각 로그가 쌓이면 국가별 피크로 알림 시각을 조정한다.
- 미조사: 국가별 숏게임 플레이 규모와 SNS 공유 피크 시간.
