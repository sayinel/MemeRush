# MVP 게임 화면 스타일 점검 (핏, 2026-10-24)

> 대상: https://meme-rush-meme-rush.vercel.app/c/2026-10-24 (390×844 모바일, 헤드리스 브라우저로 인트로→3라운드→결과→랭킹까지 직접 플레이). 캡처는 `art/review-mvp-1024/`. 확인하지 못한 것: 다른 화면 크기, 성공(Perfect) 결과, 실제 손가락 터치 감각.

## 결론
챔피언 스타일의 기본(색 토큰, 스티커 테두리, 굵은 외곽선 자막, 주인공 표정 교체)은 의도대로 들어갔다. 다만 그림 대부분이 아직 코드로 그린 임시 그림이라 "챔피언 시안"의 사무실 분위기와 보스 캐릭터가 빠져 있다. 아래 8가지를 고치면 의도에 가깝다. 새 그림(PR #44)을 넣는 것이 대부분의 해결책이다.

## 잘 된 점
- 하늘색 방사광 + 금색 타이머 패널 + 굵은 흰 외곽선 자막이 챔피언 시안과 같은 계열이다(3·4·5번 캡처).
- 주인공이 상황에 맞게 표정을 바꾼다: 대기=웃음→긴장=식은땀→실패=눈물(랭킹 화면). 확정한 표정 9종 활용이 정확하다.
- 랭킹 화면의 WORLD/FRIENDS 메달, 왕관, Global·Friends 탭 구성이 잘 읽힌다.

## 고칠 것 (우선순위순)

### P0
1. **게임 화면이 세로 전체를 채우지 않는다.** 라운드 중 장면이 화면 높이의 약 82%(844px 중 약 690px)에서 끝나고 아래가 단색 파란 띠다(2·3번 캡처). 가이드 7절(전체 채움)에 어긋난다. 캔버스를 화면에 꽉 차게(cover) 맞추고, 위아래 25%는 조용한 그림으로 둔다.
2. **결과 화면의 보스가 검은 사각형에 화난 얼굴을 붙인 임시 그림이다.** 왼쪽 화면 밖으로 잘리기도 한다(4번 캡처). 챔피언 보스(갈색 둥근 머리, 짙은 회색 정장)로 교체한다. `boss_walk`·`boss_grab`은 아직 못 만들었으니 도착하기 전에는 보스를 빼는 편이 낫다. 임시 그림이 챔피언 스타일을 해친다.
3. **배경과 소품이 챔피언 시안이 아니다.** 하늘+구름 배경, 갈색 문, 단색 빨간 버튼, 연푸른 봉투가 코드로 그린 그림이다. PR #44의 `bg_office`, `bg_win`/`bg_lose`, `clock_button`, `door`, `email_pile`, `meeting_card`, `timer_panel`, `banner_gold`, `trophy`로 교체한다. 코드 그림은 파일이 없을 때 대체용으로만 둔다.

### P1
4. **라운드 시작 배너에 작은 글씨가 주인공 위에 겹친다**(2번 캡처, "Clock out at exactly 5:00:00..."). 이 문구는 인트로에만 두거나 자막 구역(위아래 25%)으로 옮긴다.
5. **결과 판정이 두 번 나온다.** "NOT SO FAST."(큰 자막)와 카드 안 "Too early."(작은 글씨)가 겹치고, 랭킹 화면은 또 "So close"다. 판정은 한 곳에 한 번만 큰 자막으로 둔다. 문구도 어긋난다: 7.862s 차이인데 "So close"는 오해를 부른다. 합산 오차로 구간을 나눈다(예: 0.05s 이하 Perfect, 0.5s 이하 So close, 그 위 Not so fast).
6. **실패 때 색종이가 떨어진다**(3번 캡처). 색종이는 성공 전용이다. 실패는 `poof`(연기)를 쓴다.
7. **인트로가 비어 있다.** 제목 아래가 큰 빈 공간이고 주인공도 없다(1번 캡처). 후킹 이미지(`web/public/og-default.png`)나 주인공 식은땀 표정을 넣는다. 닉네임 입력 전 "Play now" 버튼이 흐린 청록이라 비활성처럼 보이는데, 활성화 이유(닉네임 필요)를 placeholder나 보조 문구로 알려 준다.
8. **리더보드에 테스트 닉네임이 섞여 있다**(e2e_prod, ui_Sam, og_test, vid_test 등 5번 캡처). 시연 전에 비우거나 닉네임 필터로 숨긴다. 평가자 눈에는 가짜 데이터로 보인다.

### P2 (여유 있으면)
- 흰색 큰 숫자("7.862s off")가 하늘색 위에서 대비가 약하다. 자막 규칙(흰 글씨 + 검은 외곽선)을 숫자에도 쓴다.
- 상단 라운드 칩(R1 +1.019s)이 작다. 최소 12px을 지킨다.
