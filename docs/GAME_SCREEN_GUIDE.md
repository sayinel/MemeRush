## 1. 범위: 게임 안의 그림과 문구를 정한다

규칙: 이 가이드는 게임 장면(대기, 탭, 결과 세 가지), 결과 영상, 공유 카드의 그림과 자막을 정한다. 랭킹·후보 관리·확인 창 같은 서비스 화면은 서비스 화면 가이드(MEME_RUSH_SCREEN_GUIDE)가 정한다. 두 가이드가 부딪히면 게임 안에서는 이 가이드가, 게임 밖 화면에서는 서비스 화면 가이드가 이긴다.
적용: 게임 틀이 그리는 모든 장면, 영상 컷, 공유 카드, 미리보기(OG) 이미지.
값:
```text
이 가이드        캐릭터, 배경, 소품, 효과, 자막, 영상 컷, 공유 카드, OG 이미지
서비스 화면 가이드  랭킹(Global·Friends), 후보 관리, 확인 창, 버튼·칩, 안내 문구
```

## 2. 스타일 이름은 "챔피언 밈"이다

규칙: 광택 있는 캐주얼 게임의 완성도(굵은 윤곽, 윤기 나는 버튼, 밝은 하늘)에 밈의 문법(반응 짤 같은 표정, 흰 테두리 스티커, 굵은 자막, 엉뚱한 소품)을 더한다. 귀엽기만 한 그림은 쓰지 않는다. 한 장면에는 웃음 포인트가 하나 있다(표정, 소품, 자막 중 하나가 주인공).
적용: 모든 그림.
값:
```text
기준 그림  art/champion/ 의 4장(플레이, 챔피언, 아쉬운 결과, 공유 카드), 사장님 확정 2026-10-24
탈락      art/rejected/ (일반 캐주얼 느낌이 강해 밈 게임으로 읽히지 않았음)
```

## 3. 색은 정해진 토큰만 쓴다

규칙: 하늘은 sky에서 sky-light로 내려가는 그라데이션이다. 캐릭터는 mascot(몸), mascot-light(하이라이트), mascot-line(윤곽선)을 쓴다. 스티커 테두리는 outline-white, 어두운 곳의 글자와 그림자는 ink, 큰 숫자 윤곽선은 navy다. 성공 장면의 빛과 트로피는 gold, 내 기록 강조는 hot, 되돌릴 수 없는 일은 red, 주 버튼은 green이다. 목록에 없는 색은 쓰지 않는다.
적용: 모든 그림과 자막.
값:
```css
:root{--sky:#29BAF5;--sky-light:#B9E9FA;--sky-deep:#0AA0FE;--navy:#1F4788;--ink:#141D24;--outline-white:#FFFFFF;
--mascot:#EC8323;--mascot-light:#EAA43B;--mascot-line:#804526;--gold:#FEDE25;--hot:#FFC531;--green:#17803F;--red:#C93A52}
```

## 4. 모든 그림은 두꺼운 흰 테두리와 갈색 윤곽을 가진다

규칙: 캐릭터와 소품은 몸 둘레에 흰 테두리(스티커 느낌)를 두르고, 안쪽 윤곽은 짙은 갈색(mascot-line)이다. 테두리 두께는 그림 짧은 변의 약 1%다. 배경에는 테두리를 두르지 않는다. 그림자는 아래쪽에 부드럽게 한 번만 둔다.
적용: 스프라이트(캐릭터, 보스, 소품)와 스티커.
값:
```text
흰 테두리   짧은 변의 약 1% (예: 1000px 스프라이트에 10px)
안쪽 윤곽   mascot-line, 흰 테두리보다 가늘게
배경        테두리 없음, 하늘은 sky → sky-light
```

## 5. 인물은 주인공 하나, 보스 하나, 소품 몇 가지다

규칙: 주인공은 주황색 둥근 직장인 캐릭터 하나다(몸 mascot). 보스는 키가 크고 어두운 색 옷을 입은 캐릭터 하나다. 오리 같은 곁다리 캐릭터는 한 장면에 하나까지 쓴다. 소품은 시계, 문, 메일 더미, 회의 초대 카드, 커피, 색종이다. 게임 설계(Playable Memes)의 MVP 아트 목록과 같다.
적용: 스프라이트 시트.
값:
```text
주인공 표정(9)  deadpan, shocked, smug, betrayed, sweating, laughing, facepalm, proud, bored
주인공 동작(5)  대기(발 동동), 달리기, 잡힘, 파묻힘, 탈출
보스 동작(2)    걷기, 잡기
소품            시계(4:59 계열), 문, 메일 더미, 회의 초대("QUICK SYNC?" 카드), 커피, 색종이
```

## 6. 글자는 그림에 굽지 않는다

규칙: 그림 안에 글자와 숫자를 넣지 않는다. 자막, 기록, 순위는 모두 코드가 얹는다. 밈 카드의 `win`/`lose` 두 컷 문구를 위아래 두 줄로 얹고, 각 줄은 60자 이하다. 그림의 위쪽 25%와 아래쪽 25%는 비워 둔다(영상 앱 UI에 가려지는 자리이기도 하다).
적용: 모든 배경, 영상 컷, 공유 카드.
값:
```text
자막 모양   흰 글씨, 검정 윤곽선 6~8px, 대문자, 굵은 압축 글꼴(Anton, OFL), 가운데 정렬
자막 자리   위 줄 = 상단 25% 안, 아래 줄 = 하단 25% 안
금지        그림 속 글자·숫자 (깨진 글자가 나오는 원인이 되고, 문구가 매일 바뀐다)
```

## 7. 화면마다 필요한 그림

규칙: 화면 하나에 배경 한 장과 스프라이트를 쓴다. 배경은 글자 없는 한 장이고, 결과 세 가지는 서로 다른 배경을 쓴다.
적용: 게임 장면과 영상.
값:
```text
인트로        밈 무대 배경 + 주인공 대기. 가운데 카드 자리(제목, 한 줄 설명은 코드)
대기(플레이)    사무실 배경 + 주인공 발 동동 + 보스가 시계로 다가옴. 화면 전체가 탭 영역
Perfect       주인공이 문으로 슬라이딩 탈출, 색종이 폭발, 우쭐한 표정
Too Early     보스가 뒷덜미를 잡아챔, 주인공 찌그러짐, 억울한 표정
Too Late      회의 초대와 메일 더미에 파묻힘, 화면 흔들림, 체념한 표정
리그 초대      주인공이 친구에게 티켓을 건네는 배경. 가운데 배너 자리
공유 카드·OG   주인공 + 트로피, 1200x630 (왼쪽 1/3은 로고 자리)
```

## 8. 파일 규격

규칙: 투명이 필요한 것은 PNG, 배경은 WebP, 영상 배경은 2배 해상도 원본이다. GIF는 쓰지 않는다. 영상은 MP4(H.264)이고 링크 미리보기는 정지 이미지다.
적용: 모든 에셋.
값:
```text
스프라이트        투명 PNG, 파일당 100KB 안팎, 2배 해상도로 제작
게임 배경         WebP, 720x1280 ~ 1080x1920, 200KB 이하 권장
영상 배경 원본     1440x2560 (9:16), PNG 또는 JPEG. 영상은 720x1280, zoompan으로 확대
OG 기본 이미지     1200x630, PNG, 1MB 이하 권장
아이콘            favicon.ico(16·32·48), icon.svg, apple-touch-icon.png(180), icon-192.png, icon-512.png
자막 폰트          WOFF2 또는 TTF를 저장소에 포함
```

## 9. 결과 영상은 결과 장면을 10초로 잇는다

규칙: 영상은 720x1280, 30fps, 10초, MP4, 무음이다. 0~3초는 밈 카드 `setup`, 3~7초는 결과 두 컷(`top` → `bottom`, `{result}`에 기록), 7~10초는 CTA와 공개 URL이다. 배경은 성공·실패 한 장씩이고 밈마다 바꾸지 않는다. 자막 문구는 코드에 고정하지 않고 밈 카드에서 가져온다.
적용: `/api/videos`.
값:
```text
0-3초   훅: setup 문구
3-7초   top 문구 → bottom 문구, {result}는 기록(예 "0.034s off")
7-10초  CTA + 공개 챌린지 URL (ref 없음)
```

## 10. 지킬 것

규칙: 밈의 이미지·캐릭터·실존 인물·상표·음원은 쓰지 않고 형식·문구·숫자·순간만 가져온다. 특정인 조롱, 혐오, 약물·성적 암시는 쓰지 않는다. 실패 장면은 플레이어 캐릭터 자신을 놀리는 데서 그친다. 보스는 특정 실존 인물을 닮게 그리지 않는다.
적용: 모든 그림과 문구.
값:
```text
승인    AI가 만든 그림과 문구는 사람이 보고 승인한 뒤에만 커밋
도구    그림을 만든 도구와 경로는 문서·커밋·PR에 적지 않는다
```

## 11. 그림을 넣기 전에 점검한다

규칙: 아래를 모두 통과해야 에셋 폴더에 넣는다. 하나라도 걸리면 다시 만든다.
적용: 새 그림 한 장마다.
값:
```text
[ ] 그림 안에 글자·숫자가 없다
[ ] 위·아래 25%가 비어 있다 (자막 자리)
[ ] 표정이 한 가지로 또렷하다 (귀엽기만 하지 않다)
[ ] 흰 테두리와 갈색 윤곽이 있다 (스프라이트)
[ ] 색이 3절 토큰 안이다
[ ] 기존 밈·캐릭터·실존 인물이 없다
[ ] 크기가 8절 규격이다
[ ] 챔피언 4장과 나란히 놓아도 같은 세계로 보인다
```
