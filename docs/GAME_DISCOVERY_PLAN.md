# Meme Rush 게임 후보 발굴 로직 슈퍼프로젝트 계획 (2026-10-24)

Meme Rush는 매일 하나의 30초 미니게임을 내놓는다. 이 계획은 "오늘의 게임 후보를 찾는 방법"을 사람이 아닌 로직으로 만들어, 매일 같은 기준으로 후보 카드 5개를 뽑고 사람은 하나만 고르게 하는 것이 목표다. 오늘 하루에는 v0(오프라인 시험이 가능한 로직)까지 만든다.

## 목표와 범위

- 목표: 입력(신호 수집 결과)에서 출력(후보 카드 5개, 근거 링크 검증 결과 포함)까지 한 번에 돌아가는 발굴 로직 v0.
- 오늘 범위: 로직(점수·걸러내기·규칙 추출·링크 검증·카드 만들기), 시험 자료 기반 시험, 명령 한 줄 실행.
- 범위 밖: 실제 서비스 운영 자동화(매일 예약 실행), 유료 데이터 구매, 개인정보 수집, 원작 이미지·소리 사용.

## 어떤 문제를 푸나 (오늘 조사에서 확인한 사실)

- 검색 기반 조사가 낸 근거 링크 6개 중 3개만 열렸다(404 두 개, 접속 제한 한 개). 조회수와 순위 같은 수치는 대부분 확인할 수 없었다.
- 그래서 발굴 로직의 핵심은 "후보를 많이 찾는 것"이 아니라 "링크를 열어 대조한 것과 못 한 것을 구분해 점수에 반영하는 것"이다.

## 파이프라인 (6단계)

1. 신호 수집: 소스별 어댑터가 후보 이름, 링크, 지표(좋아요·조회·업보트·순위), 측정 시각을 모은다.
   - 소스 후보: CrazyGames 급상승, itch.io HTML5 인기, Reddit(r/WebGames 등) 인기글, 검색 연동 질의(보조), Google Trends(보조).
   - 어댑터는 서로 바꿔 끼울 수 있게 같은 모양(이름, 링크, 지표, 시각, 소스)으로 출력한다. 접속이 막히면 해당 소스만 "수집 실패"로 기록하고 계속한다.
2. 링크 검증: 각 링크를 실제로 열어 응답 코드와 후보 이름 포함 여부를 확인한다. 결과는 `확인됨 / 열림-이름불일치 / 열리지 않음 / 미확인`으로 기록한다.
3. 적합도 점수(규칙 기반, 아래 식).
4. 걸러내기: 필수 기준을 못 맞추면 탈락시키고 이유를 남긴다.
5. 규칙 추출: 후보의 핵심 규칙을 한 줄로 추상화하고, 그림·이름·소리·상표 위험 요소 목록과 "새 겉모습" 제안을 붙인다.
6. 후보 카드 출력: 상위 5개를 JSON과 마크다운 카드로 낸다. 사람이 하나를 고르면 `선택 기록`을 남긴다.

## 점수식 (v0, 가중치는 시험하며 조정)

적합도 = 필수 기준 통과(0 또는 1) x (구현 쉬움 30 + 한 판 길이 15 + 점수 단순성 20 + 조작 단순성 15 + 신호 강도 10 + 링크 신뢰도 10) - 저작권 위험 감점(0~30)

- 필수 기준: 한 판 30초 이내, 탭·스와이프만으로 가능, 점수가 숫자 하나로 나옴.
- 신호 강도는 지표의 최근 증가를 로그 눈금으로 환산하고, 측정 시각이 7일을 넘으면 절반으로 줄인다.
- 링크 신뢰도: 확인됨 10, 열림-이름불일치 4, 열리지 않음 0, 미확인 0. 카드에는 항상 상태를 함께 표시한다.
- 저작권 위험 감점: 유명 상표·캐릭터·음원이 규칙의 일부이면 최대 30, 이름만 겹치면 10.

## 입력과 출력 형식

- 입력(`signals.json`): 항목마다 `name, url, source, metrics{}, measured_at, notes`.
- 출력(`candidates.json`, `CANDIDATES.md`): 항목마다 `rank, name, score, rule_one_line, session_length, controls, score_type, new_skin, ip_risks[], link_status, evidence_url, picked`와 아래 "인기 근거와 배경" 필드.

## 후보 카드에 반드시 보여 줄 것: 인기 근거와 배경 (사장님 요구 2026-10-24)

후보가 올라오면 "왜 지금 뜨는지"가 한눈에 보여야 한다. 카드마다 다음을 표시한다.

1. 소셜 인기 근거 랭킹: 어느 플랫폼에서(예: CrazyGames 주간, itch.io HTML5, Reddit r/WebGames, TikTok 해시태그) 몇 위인지, 지표(좋아요·조회·업보트)와 측정 시각, 근거 링크와 링크 검증 상태. 순위와 수치를 얻지 못한 소스는 "미확인"으로 표시하고 점수에서 뺀다.
2. 유행 밈 내용: 어떤 밈이나 챌린지가 이 게임의 인기와 연결되는지(예: 특정 영상 형식, 따라 하기 챌린지, 유행 문구), 그 밈이 언제부터 퍼졌는지 한두 문장과 근거 링크.
3. 인기 요인 점수(각 0~10, 합계도 표시): 상승 속도(최근 증가), 도달 규모(절대 지표), 공유하기 쉬움(결과를 한 줄로 자랑할 수 있는가), 밈 연결도(지금 유행하는 밈과 이어지는가), 재도전 유인(아슬아슬함, 짧은 판).
4. 배경 한 줄: 사람이 읽는 설명(예: "시간 맞추기 영상이 짧은 영상 플랫폼에서 반복 유행, 한 번 탭으로 끝나 따라 하기 쉬움").
5. 근거 신뢰도: 인기 근거 중 링크로 확인된 비율. 확인된 근거가 하나도 없으면 카드 맨 위에 "인기 근거 미확인" 경고를 붙인다.

추가 출력 필드: `popularity_evidence[]`(platform, rank, metric, value, measured_at, url, link_status), `meme_context`(summary, since, url), `popularity_scores`(velocity, reach, shareability, meme_link, replay_drive, total), `background_line`, `evidence_confidence`.

적합도 점수의 "신호 강도 10"은 위 인기 요인 점수 합계를 10점 만점으로 환산해 쓴다. 인기 요인 점수를 매길 근거가 없으면 해당 항목은 0점으로 두고 이유를 카드에 쓴다.

## 진행표 (한 단계가 끝날 때마다 고친다)

| 순서 | 항목 | 담당 | 시각(가정) | 상태 | 통과 조건 |
|---|---|---|---|---|---|
| 0 | 계획 문서 PR 올림 | 탐 | 13:00 | 진행 | 이 PR |
| 1 | 입력·출력 형식과 점수식 확정, 시험 자료(신호 10건) 준비 | 탐 | 13:30 | 대기 | 예시 신호 10건과 정답 순위표 |
| 2 | 링크 검증기, 점수·걸러내기, 규칙 카드 로직 구현 | 탐(클로드 API 에이전트) | 15:00 | 대기 | 시험 통과, 명령 한 줄로 카드 5개 출력 |
| 3 | 소스 어댑터 1~2개(접속 가능한 것부터), 실패해도 계속 진행 | 탐 | 16:00 | 대기 | 실제 신호 수집 1회 성공 기록 |
| 4 | 오늘의 판 선정과 "뽑힌 이유" 화면 자료 만들기(소셜 인기 근거 랭킹, 유행 밈 내용, 인기 요인 점수, 배경 한 줄 표시) | 탐 | 16:30 | 대기 | 후보 5개 카드에 인기 근거·밈·점수·배경이 모두 표시되고 비교표가 나옴 |
| 5 | 사람 선택 기록, 점수식 보정(사장님 선택과 점수 순위의 차이 반영) | 사장님·탐 | 17:00 | 대기 | 선택 기록 1건 |

시간이 모자라면 3단계를 줄이고 시험 자료로 시연한다. 단, 링크 검증기(2단계)는 줄이지 않는다.

## 시험과 완료 증거

- 단위 시험: 점수식 계산, 필수 기준 탈락, 감점 적용, 측정 시각 7일 초과 감쇠, 링크 상태별 점수.
- 링크 검증 시험: 응답 코드 200, 404, 429, 시간 초과를 흉내 낸 응답으로 상태 분류를 확인한다.
- 통합 시험: 시험 자료 10건에서 정답 순위표와 상위 5개가 일치하는지 확인한다.
- 카드 표시 시험: 모든 후보 카드에 인기 근거 랭킹, 유행 밈 내용, 인기 요인 점수 5개 항목과 합계, 배경 한 줄, 근거 신뢰도가 있고, 근거가 없으면 경고 문구가 붙는지 확인한다.
- 완료 증거: 시험 통과 개수, 명령 한 줄 실행 출력, 후보 카드 5개 파일.

## 위험과 막는 법

- 소스 접속이 막힌다(오늘 429·404를 실제로 겪었다): 소스별로 독립 실행하고, 실패는 기록하고 건너뛴다. 시험 자료로 시연할 길을 열어 둔다.
- 검색 기반 수치를 믿고 점수가 왜곡된다: 링크 검증을 점수에 넣고, 미확인 수치는 신호 강도에서 제외한다.
- 저작권: 규칙은 참고하고 그림·이름·소리는 새로 만든다. 위험 요소 목록을 카드에 항상 붙인다.
- 점수식이 사람의 직관과 다르다: 5단계에서 사장님 선택과 순위 차이를 기록해 가중치를 고친다.

## 열린 결정

- 오늘의 첫 게임(추천: 스톱워치 타이머 정지). 첫 게임이 정해지면 시험 자료에 정답을 반영한다.
- 이 로직을 저장소 안 `tools/discovery/`에 둘지, 별도 저장소로 둘지.
