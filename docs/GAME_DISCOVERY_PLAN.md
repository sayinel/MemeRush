# Meme Rush 게임 후보 발굴 로직 슈퍼프로젝트 계획 (2026-10-24)

Meme Rush는 매일 하나의 30초 미니게임을 내놓는다. 이 계획은 "오늘의 게임 후보를 찾는 방법"을 사람이 아닌 로직으로 만들어, 매일 같은 기준으로 후보 카드 5개를 뽑고 사람은 하나만 고르게 하는 것이 목표다. 오늘 하루에는 v0(오프라인 시험이 가능한 로직)까지 만든다.

## 목표와 범위

- 목표: 입력(신호 수집 결과)에서 출력(후보 카드 5개, 근거 링크 검증 결과 포함)까지 한 번에 돌아가는 발굴 로직 v0.
- 오늘 범위: 로직(점수·걸러내기·규칙 추출·링크 검증·카드 만들기), 시험 자료 기반 시험, 명령 한 줄 실행.
- 범위 밖: 실제 서비스 운영 자동화(매일 예약 실행), 유료 데이터 구매, 개인정보 수집, 원작 이미지·소리 사용.

## 어떤 문제를 푸나 (오늘 조사에서 확인한 사실)

- 검색 기반 조사가 낸 근거 링크 6개 중 3개만 열렸다(404 두 개, 접속 제한 한 개). 조회수와 순위 같은 수치는 대부분 확인할 수 없었다.
- 그래서 발굴 로직의 핵심은 "후보를 많이 찾는 것"이 아니라 "수치의 출처와 규모를 구분해 인기도로 판단하는 것"이다. 처음에는 링크로 대조한 것과 못 한 것을 구분해 점수에 넣으려 했으나, 2026-10-24에 기준을 바꿨다(아래 "인기도 기준 변경" 절). 링크 열림은 화면에 보여 주는 정보로만 남는다.

## 파이프라인 (6단계)

1. 신호 수집: 소스별 어댑터가 후보 이름, 링크, 지표(좋아요·조회·업보트·순위), 측정 시각을 모은다.
   - 소스 후보: CrazyGames 급상승, itch.io HTML5 인기, Reddit(r/WebGames 등) 인기글, 검색 연동 질의(보조), Google Trends(보조).
   - 어댑터는 서로 바꿔 끼울 수 있게 같은 모양(이름, 링크, 지표, 시각, 소스)으로 출력한다. 접속이 막히면 해당 소스만 "수집 실패"로 기록하고 계속한다.
2. 링크 검증: 각 링크를 실제로 열어 응답 코드와 후보 이름 포함 여부를 확인한다. 결과는 `확인됨 / 열림-이름불일치 / 열리지 않음 / 미확인`으로 기록한다. 같은 링크는 한 번 실행에서 한 번만 열고, 응답 본문은 크기 상한까지만 읽는다. 결과는 카드에 표시용으로 붙고 점수·탈락에는 쓰지 않는다(아래 "인기도 기준 변경").
3. 적합도 점수(규칙 기반, 아래 식).
4. 걸러내기: 필수 기준을 못 맞추면 탈락시키고 이유를 남긴다.
5. 규칙 추출: 후보의 핵심 규칙을 한 줄로 추상화하고, 그림·이름·소리·상표 위험 요소 목록과 "새 겉모습" 제안을 붙인다.
6. 후보 카드 출력: 상위 5개를 JSON과 마크다운 카드로 낸다. 사람이 하나를 고르면 `선택 기록`을 남긴다.

## 점수식 (v0, 가중치는 시험하며 조정)

적합도 = 필수 기준 통과(0 또는 1) x (구현 쉬움 30 + 한 판 길이 15 + 점수 단순성 20 + 조작 단순성 15 + 인기도 20) - 저작권 위험 감점(0~30)

(v0 초안은 "신호 강도 10 + 링크 신뢰도 10"이었다. 2026-10-24에 링크 신뢰도 항목을 없애고 인기도 20으로 합쳤다. 합계 100은 그대로.)

- 필수 기준: 원본 게임의 한 판이 30초 이내(상한만 두며 하한은 없다. 짧은 게임을 찾는 것이다), 탭·스와이프만으로 가능, 점수가 숫자 하나로 나옴. 한 판 30~60초는 MemeRush 한 판(3라운드)의 길이이며 원본 게임의 기준이 아니다([GAME_FRAME_SPEC.md](GAME_FRAME_SPEC.md) 2절).
- 인기도(0~100)는 온라인 인기도와 커뮤니티 인기도를 합의도(독립 출처 수)로 보정한 값이고, 총점/100 x 20이 적합도에 들어간다. 온라인 근거는 측정 시각이 7일을 넘으면 절반으로 줄인다.
- 링크 상태(`확인됨 / 열림-이름불일치 / 열리지 않음 / 미확인`)는 카드에 항상 표시하되 점수에는 넣지 않는다.
- 저작권 위험 감점: 유명 상표·캐릭터·음원이 규칙의 일부이면 최대 30, 이름만 겹치면 10. 영문 용어는 단어 경계로 비교한다(`sonic`이 `ultrasonic`에 걸리지 않게).

## 인기도 기준 변경 (사장님 결정 2026-10-24)

- 바뀐 기준: 인기는 링크가 열리는지가 아니라 **온라인 인기도**(검색 관심, 영상 조회·해시태그 규모, 포털·스토어 순위, 확산 속도)와 **커뮤니티 인기도**(여러 커뮤니티에서 독립적으로 반복 언급·추천된 정도, 업보트 규모, 반대 의견)로 판단한다. 링크 열림 검사는 정보 표시용으로만 남기고 점수·탈락에 쓰지 않는다. 그래서 v0 점수식의 "링크 신뢰도 10"은 없어지고, "신호 강도 10"은 "인기도 20"으로 바뀌었다.
- 이유: 링크가 열려도(200) 그 글이 인기를 증명하지 않고, 접속 제한(429, 403)이나 삭제된 글(404)은 인기가 없다는 뜻이 아니다. 오늘 조사에서도 링크 6개 중 3개만 열렸지만 열리지 않은 것이 인기가 없다는 증거는 아니었다. 인기는 규모(조회·업보트), 독립 출처 수(합의도), 반대 의견으로 직접 재는 편이 맞다고 보았다.
- 원래 계획의 의도는 유지된다. "검증하지 못한 수치가 점수를 왜곡하지 않게 한다"는 목표를 링크 열림 대신 아래 장치로 이룬다: 독립 출처가 하나뿐이면 "단일 출처" 표시와 총점 x0.7, 재인용은 규모에 넣지 않음, 식는 신호 -10, 인위적 바이럴 의심 -15, 7일 넘은 근거 절반, 추론값 표시("추론값, 신뢰 낮음").
- 코드 위치: `tools/discovery/discovery/popularity.py`(인기도), `weights.json`(가중치), `scoring.py`(적합도). 계산식과 입력 형식은 `tools/discovery/README.md`.

## 입력과 출력 형식

- 입력(`signals.json`): 항목마다 `name, url, source, metrics{}, measured_at, notes`.
- 출력(`candidates.json`, `CANDIDATES.md`): 항목마다 `rank, name, score, rule_one_line, session_length, controls, score_type, new_skin, ip_risks[], link_status, evidence_url, picked`.

## 진행표 (한 단계가 끝날 때마다 고친다)

| 순서 | 항목 | 담당 | 시각(가정) | 상태 | 통과 조건 |
|---|---|---|---|---|---|
| 0 | 계획 문서 PR 올림 | 탐 | 13:00 | 진행 | 이 PR |
| 1 | 입력·출력 형식과 점수식 확정, 시험 자료(신호 10건) 준비 | 탐 | 13:30 | 대기 | 예시 신호 10건과 정답 순위표 |
| 2 | 링크 검증기, 점수·걸러내기, 규칙 카드 로직 구현 | 탐(클로드 API 에이전트) | 15:00 | 대기 | 시험 통과, 명령 한 줄로 카드 5개 출력 |
| 3 | 소스 어댑터 1~2개(접속 가능한 것부터), 실패해도 계속 진행 | 탐 | 16:00 | 대기 | 실제 신호 수집 1회 성공 기록 |
| 4 | 오늘의 판 선정과 "뽑힌 이유" 화면 자료 만들기 | 탐 | 16:30 | 대기 | 후보 5개 카드와 비교표 |
| 5 | 사람 선택 기록, 점수식 보정(사장님 선택과 점수 순위의 차이 반영) | 사장님·탐 | 17:00 | 대기 | 선택 기록 1건 |

시간이 모자라면 3단계를 줄이고 시험 자료로 시연한다. 단, 링크 검증기(2단계)는 줄이지 않는다.

## 시험과 완료 증거

- 단위 시험: 점수식 계산, 필수 기준 탈락(원본 한 판 30초 상한), 감점 적용, 측정 시각 7일 초과 감쇠(실제 점수 경로), 링크 열림이 점수에 영향이 없음.
- 링크 검증 시험: 응답 코드 200, 404, 429, 시간 초과를 흉내 낸 응답으로 상태 분류를 확인한다.
- 통합 시험: 시험 자료 10건에서 정답 순위표와 상위 5개가 일치하는지 확인한다.
- 완료 증거: 시험 통과 개수, 명령 한 줄 실행 출력, 후보 카드 5개 파일.

## 위험과 막는 법

- 소스 접속이 막힌다(오늘 429·404를 실제로 겪었다): 소스별로 독립 실행하고, 실패는 기록하고 건너뛴다. 시험 자료로 시연할 길을 열어 둔다.
- 검색 기반 수치를 믿고 점수가 왜곡된다: 링크 열림이 아니라 독립 출처 수(합의도), 단일 출처 감점, 7일 넘은 근거 감쇠, 추론값 표시로 막는다. 링크 상태는 카드에 표시해 사람이 판단한다.
- 저작권: 규칙은 참고하고 그림·이름·소리는 새로 만든다. 위험 요소 목록을 카드에 항상 붙인다.
- 점수식이 사람의 직관과 다르다: 5단계에서 사장님 선택과 순위 차이를 기록해 가중치를 고친다.

## 열린 결정

- 오늘의 첫 게임(추천: 스톱워치 타이머 정지). 첫 게임이 정해지면 시험 자료에 정답을 반영한다.
- 이 로직을 저장소 안 `tools/discovery/`에 둘지, 별도 저장소로 둘지.
