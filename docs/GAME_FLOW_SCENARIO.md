# 게임 플로우와 게임 시나리오 (1.0 정본, 2026-10-30 초안)

게임 화면·연출을 만들거나 고칠 때는 이 문서를 **먼저** 고치고, 그다음 시안과 코드를 고친다. 규칙·점수·틀은 `MEME_GAME_DESIGN.md`, 그림 규격은 `GAME_SCREEN_GUIDE.md`, 틀 공통 규격은 `GAME_FRAME_SPEC.md`가 정본이고 여기서는 되풀이하지 않는다.

## 1. 플로우 (사용자가 밟는 순서)

1. **유입**: 사장님 SNS(한국 타겟 버전) 또는 주요 커뮤니티(글로벌 버전)의 링크. 링크에 `?lang=ko|en`, `?src=sns_kr|community_global`을 붙인다. 언어는 링크값, 저장된 선택, 브라우저 언어 순으로 정하고 상단 KO/EN 전환으로 바꿀 수 있다.
2. **첫 화면(인트로)**: 게임 이름 `MEME RUSH #001`, 오늘 게임 `TOAST CAM`, 시작 버튼. PC는 좌우에 소개·순위 영역이 붙는다(B안).
3. **판 시작**: 카운트다운 3-2-1-GO, 그 뒤에 시계가 움직인다. 1라운드 3초, 2라운드부터 2초 카운트다운.
4. **한 판 입력**: 목표 시각에 맞춰 누른다(버튼, 화면 탭, Space·Enter).
5. **판정 → 결과**: 4절의 판정별 결과 화면. 3라운드를 마치면 최종 결과로 간다.
6. **랭킹**: 결과 화면의 "내 순위 보기". 월드 랭킹만 보이고 친구 랭킹은 1.0에서 뺐다.
7. **메일 받기(CTA)**: 랭킹 화면의 "밈 게임 메일로 받기" → 이메일 입력 → 보냄 완료. 우리는 이메일만 수집한다. 서버는 아직 없다.
8. **다시 도전 / 공유**: 결과·랭킹의 "다시 도전", "공유하기"(링크 복사).

화면 흐름도 아티팩트: https://claude.ai/artifact/NgG8y52hkyw3q7Qe2j8seS

## 3. 언어 두 종류

- **한국 타겟**: 화면은 영어, 행동(CTA급) 문구만 한글: "다시 도전", "내 순위 보기", "밈 게임 메일로 받기", "공유하기", 안내문 "이 게임을 메일로 받고, 새로운 게임알림을 받으세요."
- **글로벌**: 전부 영어: "Try again", "See my rank", "Email me this game", "Share".
- 영문 문구와 한글 자막 초안은 핏 작성, 사장님 확인 대기.

## 4. 시나리오: 판정별 연출

주인공은 야근하는 직장인이고 보스가 지켜본다. 감정은 시작 땀, 끝 눈물이다.

- **시작(조마조마)**: 땀 흘리는 표정, 몸이 달달 떨린다. 땀방울 오버레이(미구현, 제안 단계).
- **Too Late(늦게 누름)**: 우는 주인공, 오리가 머리 위에서 놀리듯 까딱, 위쪽에 판정+초+베스트·월드 순위를 한 덩어리로. 눈물 흐름(미구현, 제안 단계).
- **Too Early(일찍 누름)**: 보스에게 걸림. 보스 화남 컷이 크게 나온다. 주인공 뒷덜미를 잡는 컷은 없다.
- **성공(Perfect/Nice)**: 별 터짐만, 색종이 없음. 자신만만한 주인공 표정, 자막 초안 "BOSS HAS NO NOTES".
- **최종 엔딩은 코드상 둘로 갈린다**(코드 `playFinal`, DevGame 판정 근거): 3판을 마치고 가장 나쁜 판의 오차가 300ms를 넘으면 실패이고, 그 가장 나쁜 판이 **일찍 누른 것이면 보스가 주인공을 붙잡고 끌고 나가는 엔딩(`finalGrabbed`)**, **늦게 누른 것이면 회의 서류 카드에 파묻히는 엔딩(`finalBuried`)**이다. 즉 "3판 다 실패하면 끌려간다"가 아니라 "가장 나쁜 판이 일찍이었을 때 끌려간다"다(사장님 기억과 다름, 코드 기준, 10/30 확인).
- 끌려가는 엔딩(`finalGrabbed`): 보스가 왼쪽에서 들어오고 주인공이 놀라 옆으로 비킨 뒤 화면이 흔들리고 손이 주인공을 잡으며, 셋이 왼쪽으로 220px만 움직이고 멈춘다. 화면 밖까지 끌고 나가지 않고 연출도 약 1.5초라 사장님도 찾기 어려웠다(10/30). 사장님 지시: 주인공이 보스에게 끌려 **화면 밖으로** 나가야 한다. 고칠 것. 보스 걷기·붙잡기 그림은 아직 없어 코드로 그린 임시 보스가 나온다.
- **정본 장면은 트레일러**(`/trailer.mp4` 0:51 부근, 사장님 10/30): 세 판이 모두 일찍 눌림(R1 -1.429s, R2 -2.928s, R3 -3.915s), 자막 "NOT SO FAST.", 화난 보스(검은 정장)가 주인공을 붙잡고 오른쪽 문 쪽으로 데려가며 자막 "BACK TO YOUR DESK". 문 그림(`door.png`)이 이미 있다. 구현은 이 장면을 따른다.
- 끌려나간 뒤 화면(빈 사무실 + GAME OVER 추천)은 사장님 확인 대기.
- 파묻히는 엔딩(`finalBuried`)을 1.0에 쓸지는 미정.

## 5. 정해진 것과 미정

정해진 것(밈러시-슈퍼프로젝트 카드 #30~#54): 기본 흐름(SNS → 이메일 → 메일 발송), 보스 정본(짙은 회색 캡슐 머리 시트), 우리 단독 프로젝트(공개 저장소 금지), 시간 시작 방식(카운트다운 뒤 시작), PC 중앙 박스 B안, 결과·랭킹 시안, 한국 타겟/글로벌 2종, 종이폭죽 제거, 친구 랭킹 제거.

미정: 성공 때 색종이 처리 최종 확인, 눈물·땀 연출 선택, 끌려나간 뒤 화면, 언어 분기 방식 최종(링크 둘 + 상단 전환으로 구현됨), 메일 발송 서버(탐 단계표 #28).
