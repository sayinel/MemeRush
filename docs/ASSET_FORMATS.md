# 이미지·영상 에셋 형식 정리 (2026-10-24, 핏)

MVP_SCOPE의 기술 기반(Next.js + Vercel + Supabase + 서버 ffmpeg, 720×1280 10초 MP4, 1200×630 OG PNG)에 맞춰 어떤 파일 형식이 필요한지 정리했다. 조사는 검색 연동 AI 리서치이고, 공식 문서로 대조하지 못한 항목은 "대조 전"으로 표시했다.

## 결론
- **GIF는 필요 없다.** 공유 영상은 MP4(H.264)로 통일한다. GIF는 용량이 MP4보다 훨씬 크고(리서치 값 10~20배, 대조 전), 인스타그램·틱톡 같은 앱은 파일 공유에서 비디오(MP4)만 받는다.
- **링크 미리보기(OG)는 정지 이미지다.** 어떤 플랫폼도 GIF를 움직이는 미리보기로 쓰지 않는다. 따라서 PNG 또는 JPEG 1장이면 된다.
- **게임 화면 에셋은 PNG(투명)와 WebP(배경)**, 아이콘은 SVG·PNG다.

## 필요한 파일 목록
1. 영상 배경 원본 2장(성공·실패): PNG 또는 JPEG, 1440×2560(9:16). 영상은 720×1280이고 `zoompan`으로 확대하므로 원본이 2배는 커야 깨지지 않는다. 위·아래는 자막 자리로 비워 둔다.
2. `og-default.png`: 1200×630, PNG, 1MB 이하 권장. 동적 OG(`/api/og`)도 같은 크기.
3. 게임 화면 배경: WebP, 720×1280~1080×1920, 200KB 이하 권장.
4. 캐릭터·스티커·버튼: 투명 PNG(또는 WebP), 파일당 100KB 안팎, 2배 해상도로 만든다.
5. 아이콘: `favicon.ico`(16·32·48), `icon.svg`, `apple-touch-icon.png`(180×180, 불투명), `icon-192.png`, `icon-512.png`.
6. 카카오톡 공유 썸네일은 선택(카카오 메시지 템플릿을 쓸 때만): 800×800 또는 800×400.
7. 자막 폰트: WOFF2 또는 TTF를 저장소에 넣는다(영상 자막과 OG 이미지에서 사용).

## 플랫폼 메모 (대조 전 포함)
- OG 권장 크기는 1200×630. 용량은 Facebook 8MB, X 5MB, Discord 8MB, Telegram 5MB(리서치 값). Slack 1MB, 카카오 1MB 권장은 공식 문서로 확인하지 못했다.
- X 카드는 `summary_large_image`를 지정해야 하고, 1200×630은 위아래가 조금 잘릴 수 있다.
- iOS Safari에서 영상 자동 재생은 `autoplay` + `muted` + `playsinline`이 모두 있어야 한다(WebKit 공식 블로그).
- Vercel 함수의 요청·응답 본문은 4.5MB 제한이다. 영상 업로드는 서버를 거치지 않고 Storage로 직접 올린다.
- Supabase Storage에서 이미지를 `fetch`로 받으려면 CORS 확인이 필요하다(MVP_SCOPE 6절에도 있음).
- **자막 안전 영역**: 리서치 문서는 "위 1080px, 아래 320px"라고 했지만 1280px 높이 영상에는 말이 안 되는 수치다. 이 값은 쓰지 않는다. 대신 위·아래 각 25%를 비워 두고(약 320px), 인스타그램·틱톡 화면에서 실제로 가려지는지 한 번 확인한다.

## 우리 에셋과의 대조
- 지금 만든 세로 이미지는 1536×2752라서 영상 배경 원본(1440×2560 이상) 기준을 충족한다.
- 챔피언 시안의 자막·숫자는 그림에 구워져 있어 시안으로만 쓴다. 실제 에셋은 문구 없는 배경으로 만든다.
