# Meme Rush 가이드 인덱스

> 정본은 카빗 가이드 `MEME_RUSH_GUIDE_INDEX`. 무엇을 만들든 먼저 이 표에서 문서를 고른다.

| 가이드 | 무엇을 정하나 | 저장소 사본 | 카빗 문서 |
|---|---|---|---|
| 서비스 화면 | 게임 밖 화면(랭킹, 결과, 후보 관리, 확인 창, 버튼·칩, 문구) | [SERVICE_SCREEN_GUIDE.md](SERVICE_SCREEN_GUIDE.md) | MEME_RUSH_SCREEN_GUIDE |
| 게임 화면 | 게임 안 그림(색, 캐릭터, 자막, 화면별 그림, 영상 컷), 점검표 | [GAME_SCREEN_GUIDE.md](GAME_SCREEN_GUIDE.md) | MEME_RUSH_GAME_GUIDE |
| 에셋 | 파일 형식, 용량, 크기, 폴더, 이름, 올리기 순서 | [ASSET_GUIDE.md](ASSET_GUIDE.md) | MEME_RUSH_ASSET_GUIDE |
| 연출 | 장면별 연출, 시작값, 영상 레시피, 접근성 | [MOTION_GUIDE.md](MOTION_GUIDE.md) | MEME_RUSH_MOTION_GUIDE |

## 부딪힐 때
- 게임 안 그림은 게임 화면 가이드, 게임 밖 화면은 서비스 화면 가이드, 파일 조건은 에셋 가이드, 움직임은 연출 가이드가 이긴다.
- 같은 값이 두 곳에 있으면 게임 화면 가이드가 정본이다(자막 모양, 색, 캐릭터).

## 바뀌는 속도
- 거의 안 바뀜: 게임 화면(스타일, 색). 가끔: 서비스 화면, 에셋. 자주: 연출(플레이 테스트로 시작값 조정). 자주 바뀌는 값은 연출 가이드에만 둔다.

## 조사 원문
- 리서치 원문은 가이드가 아니라 근거 자료로 [research/](research/)에 날짜와 함께 둔다. 가이드에는 확정값과 "시작값"만 쓰고, 출처가 약한 값에는 "대조 전"을 붙인다.

## 더 쪼개지 않는다
- 게임 틀이 2개 이상이거나 외부 제작자가 들어오거나 한 문서가 15절을 넘으면 그때 캐릭터 가이드 등으로 나눈다.
