# Meme Rush 마케팅 전략 (초안)

- 작성: 마야(2026-10-24). 근거는 제미나이 검색 연동 리서치 1회(질문 5개)와 [MVP 범위](MVP_SCOPE.md)입니다.
- 한 줄 결론: **돈 쓰는 홍보 없이, 제품 안의 공유 장치(Challenge a Friend, 결과 영상)와 무료 채널 세 곳으로 시작합니다.** 유료 광고, 인플루언서 계약, 한국어 버전은 첫 재방문 숫자를 본 뒤에 정합니다.
- 이 문서의 사례 수치는 검색 결과를 그대로 옮긴 것이고, 1차 출처를 모두 직접 열어 대조하지는 못했습니다. 한계는 맨 아래에 적었습니다.

## 2. 우리가 이미 가진 장치 (MVP에 들어 있음)

1. 가입 없이 닉네임만으로 바로 플레이(익명 세션)
2. 결과 화면의 Challenge a Friend 링크와 Friends 랭킹, Global 랭킹
3. 결과 종류별 MP4 하이라이트 영상(다운로드, 파일 공유)
4. Wordle식 텍스트 공유와 OG 미리보기 이미지
5. 이벤트 기록 (유입 경로를 숫자로 볼 수 있어야 아래 지표를 잴 수 있습니다)

## 3. 단계별 계획

### 1단계. 0~30일, 재방문부터 검증
- 채널: Reddit r/WebGames, Show HN, Product Hunt, Discord 커뮤니티. 모두 비용이 없습니다.
- 올리는 조건: 직링크로 바로 플레이, 로그인·대기열 없음(Show HN 요건과 맞음). 이미 설계가 충족합니다.
- 지표: 다음 날 재방문(D1) 30% 이상을 첫 기준으로 삼습니다. 검색 결과의 업계 평균은 22~27%, 상위 퍼즐 장르는 30~40%입니다.
- 지금 하지 말 것: 유료 광고, 앱스토어 출시.

### 2단계. 31~60일, 바이럴 루프 강화
- 연속 접속 기록(Streak)을 추가합니다. 현재 MVP에서는 보류된 항목입니다.
- 챌린지 링크로 들어온 사람의 가입(플레이) 비율, 공유 버튼을 누른 비율을 매일 봅니다.
- 지표: 7일 재방문(D7) 12~15% 이상, 일일 활성/월 활성 비율 20% 이상을 목표로 둡니다(업계 상위권 기준).

### 3단계. 61~90일, 숏폼과 포털로 확장
- 결과 하이라이트 MP4를 세로 영상으로 매일 올립니다. 매일 바뀌는 밈이 곧 매일 새 영상 소재입니다. 게임 후보 발굴 로직([GAME_DISCOVERY_PLAN.md](GAME_DISCOVERY_PLAN.md))이 소재를 만드는 공정이 됩니다.
- CapCut 템플릿을 만들어 배포합니다.
- 크리에이터 협업은 선물(기프팅) 방식의 나노 크리에이터 5~15명으로 시작합니다. 검색 결과 기준 예산은 $1,000~5,000 수준이지만, 이 단계에서 승인받고 정합니다.
- CrazyGames, Poki 같은 웹게임 포털 등록을 검토합니다.

## 5. 한계와 확인할 것

1. 1차 출처 본문의 수치를 모두 직접 대조하지는 못했습니다. Reddit 규정 페이지는 접속이 거부되어(403) 열어 보지 못했습니다. 검색 결과에 나온 "계정 7일 이상, 댓글 카르마 10 이상"은 올리기 전에 규정을 직접 읽고 확인해야 합니다.
2. 스톱워치·타이밍 탭 계열 게임의 초기 사용자 수치, Discord·텔레그램 미니앱 사례, 게임별 바이럴 계수는 근거를 찾지 못했습니다.
3. D1·D7 기준은 모바일·웹 평균이라 장르와 연도가 다릅니다. 실제 우리 숫자가 나오면 이 문서의 기준을 우리 값으로 바꿉니다.
4. 이 문서는 MVP 범위(영어만, 게임 1개)를 바꾸지 않습니다. 한국어, 두 번째 게임은 D1 검증 뒤에 다시 판단합니다.
