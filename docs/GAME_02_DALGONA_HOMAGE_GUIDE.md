# 달고나 2편: 오징어 게임 오마주 안전선 (2026-11-01, 핏)

사장님 2026-11-01: 오징어 게임 오마주(초록 츄리닝 참가자, 보라색 옷의 사장 캐릭터)를 저작권 문제 없는 수준으로 넣어 본다. 이 문서는 조사 결과와 우리 쓰는 선이다. 변호사의 판단이 아니며, 상용화·유료화 전에는 변호사 확인이 필요하다.

## 조사로 확인한 것

- 서바이벌 데스 게임이라는 설정과 구도는 아이디어이고 장르 전형이라 저작권으로 독점되지 않는다는 쪽의 판결이 있다. 2025-09-30 미국 뉴욕 남부지법이 쇼 대 넷플릭스 소송을 기각했다(소유권 입증 실패, 실질적 유사성 없음, scène à faire). 출처: https://www.loeb.com/en/insights/publications/2025/10/shah-v-netflix, https://news.bloomberglaw.com/ip-law/netflix-wins-dismissal-of-squid-game-suit-by-filmmaker-1. 단, 이 판결은 "오징어 게임이 남의 작품을 베꼈나"를 다룬 것이고 "남이 오징어 게임을 오마주해도 되나"의 직접 근거는 아니다. 같은 아이디어/표현 이분법을 유추한 것이다. [추정]
- 의상 색 조합 자체는 저작권 대상이 아니지만, 출처 혼동을 일으키면 한국 부정경쟁방지법과 미국 랜햄법(트레이드 드레스) 문제가 될 수 있다(제미나이 검색 결과, 원문 미확인). 출처 후보: https://www.bizhankook.com/bk/article/22718
- 'SQUID GAME' 글자와 ○△□가 들어간 공식 로고는 넷플릭스가 상표로 등록·출원했다(USPTO: https://trademarks.justia.com/970/77/squid-97077792.html). 숫자 456, 가면 도형, 달고나 4개 모양 단독은 공식 DB에서 별도 등록 확인 못 함.
- 넷플릭스는 이름과 로고를 무단 사용한 상업 게임에는 삭제 요청 등을 했다(스팀 기록: https://steam-tracker.com/app/1759780/). 합법 오마주 광고 사례는 이름·번호·로고를 빼고 설정을 변형했다(예: https://www.adweek.com/brand-marketing/this-debt-relief-app-piggybacked-on-the-squid-game-craze-using-business-cards/).

## 우리가 쓰는 선

쓴다
- 초록색 운동복 참가자: 일반 트레이닝복. 한 가지 색만 따오고 디자인(줄무늬 선, 칼라, 소매 모양)은 우리 것으로 새로 그린다.
- 보라색 옷의 사장: 진행요원이 아니라 우리 게임의 '사장'으로 보라색 정장이나 점퍼를 입힌다. 얼굴이 보이는 캐릭터로 만든다.
- 달고나와 모양(하트, 별, 우산): 한국 전통 과자와 일반 도형이다. 우산은 일반 우산 윤곽이다.

피한다
- "Squid Game"·"오징어 게임" 이름과 로고, ○△□ 마크, 도형 글자체
- 가면(원·삼각형·사각형 마스크), 분홍색 진행요원 점프수트, 번호 456·001 같은 상징 번호
- 참가자 가슴 번호표(필요하면 번호 없이 이름표 없음이 가장 안전하다)
- 오징어 게임의 장면·음악·효과음 그대로 재현
- 넷플릭스를 연상시키는 홍보 문구(공식·제휴처럼 보이는 표현)

앱 소개나 SNS 글에서도 "오징어 게임 달고나"라는 이름을 팔지 않는다. 설명할 때는 "달고나 뽑기 챌린지"로 부른다.

## 에셋 반영 (요청 목록에 추가)

- 주인공: 초록 트레이닝복 버전 5표정(땀, 놀람, 자랑, 울음, 무표정). 번호 없음. 기존 직장인 버전은 1편용으로 남긴다.
- 보스(사장): 보라색 정장·점퍼 버전 걷기, 들여다보기, 고개 젓기. 마스크 없음.
