# 밈러시 #002 대본: 달고나 뽑기 챌린지 (2026-11-01 초안, 핏)

사장님 2026-11-01: 2편은 달고나로 하고, 방식은 A(타임어택 + 균열)로 시작한다. 이 문서는 게임 규칙·판정별 연출·결과 영상·카드 문구·에셋 요청을 정한 대본이다. 틀 코드(`outline_trace`)는 아직 없고 동훈 님·탐 확인이 필요하다. 근거 문서: `GAME_FRAME_SPEC.md`(틀), `GAME_FLOW_SCENARIO.md`(1.0 플로우), `GAME_SCREEN_GUIDE.md`(챔피언 밈 스타일), `ASSET_LIBRARY.md`(라이브러리 규칙).

## 1. 한 줄과 틀

한 줄: 달고나 판의 모양 테두리를 바늘로 따라가며 깨뜨리지 않는다. 한 판 약 30초.
틀: `outline_trace`(난이도 중간). 점수 유형은 정확도와 완주 시간의 합.
저작권 안전선: 오징어 게임의 그림·로고·소리는 쓰지 않는다. 별·원·삼각형 같은 일반 도형과 새로 만든 그림만 쓴다.

## 2. 규칙 (타임어택, 사장님 2026-11-01 확정)

- 3라운드, 모양이 쉬운 것에서 어려운 것으로 간다: **하트(매우 쉬움) → 별 → 우산**. 우산은 일반 우산 윤곽(물결 가장자리와 J자 손잡이)이고 오징어 게임의 그림·로고·소리는 쓰지 않는다.
- 라운드마다 제한 시간이 있고 갈수록 짧다. 현재 값은 하트 9초, 별 8초, 우산 7초(시제품 `SHAPE_LIMIT_MS`, 플레이하며 조정). 3번째 판은 될랑 말랑할 만큼 빠듯하게 맞춘다.
- 제한 시간 안에 모양 테두리를 한 번에 다 그려야 통과한다(테두리의 92% 이상). 테두리에서 허용 오차 밖으로 벗어나면 균열이 생기고, 균열 3번이면 그 판은 깨짐(실패)이다.
- **시간 안에 못 끝내면 폭탄이 터진다**(게임 종료, 랭킹 제외).
- 순위: 완주한 사람만, 정확도 높은 순, 동점이면 남은 시간이 많은 순. 마감 시간보다 빨리 끝낼수록 상위 랭커다(남은 시간이 많을수록 위).
- 서버 검증 상한: 완주 시간 하한(사람이 모양을 따라가는 최소 시간)을 둔다. 값은 틀 구현 때 정한다(시제품 시험에서 0.4초 만에 따라 그려도 클라이언트는 통과시켰다).

## 3. 판정별 연출 (주인공은 야근하는 직장인, 보스가 지켜봄)

- 시작: 침 삼키는 주인공, 땀방울. 달고나 판이 화면 가운데 크게 나오고 바늘 아이콘이 손끝에 붙는다.
- 균열 한 번: 판에 금이 가는 그림, 짧은 "깨지는" 소리, 주인공 놀람 표정.
- 균열 두 번: 금이 길어지고 화면이 살짝 흔들린다. 보스가 문 쪽에서 들여다본다.
- 완주 성공(Perfect/Nice): 판이 깨끗이 떨어져 나가는 컷, 자신만만한 주인공, 별 터짐만(색종이 없음). 자막 후보 "NO CRACKS. NO NOTES."
- 깨짐(실패): 판이 쪼개지고 우는 주인공, 보스가 들어와 고개를 젓는다. 끌려나가는 엔딩은 쓰지 않는다(1편 정본과 구분).
- 시간 초과: 폭탄이 터지는 컷(검은 폭탄, 도화선, 주황 섬광과 연기), 그을린 판 조각, 주인공이 놀라 굳는다. 색종이는 쓰지 않는다.

## 4. 결과 영상 (10초, 9:16)

- 성공 갈래: 판 클로즈업 → 완주 → 정확도 숫자가 크게 → 주인공 포즈 → 월드 순위.
- 실패 갈래: 판이 쪼개지는 순간 → 우는 주인공 → 보스 → 다시 하기 문구.
- 두 갈래 모두 마지막 한 줄은 "Beat me" 문구와 게임 주소.
