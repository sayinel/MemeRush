# 오늘의 게임 제작 라인: 조사에서 이미지까지 (2026-10-24 초안)

매일 하나의 판을 만들 때, 밈 조사 결과가 저장되고 그 저장본으로 게임 스토리와 이미지가 만들어지는 흐름을 정한다. 앞쪽은 발굴 로직(`tools/discovery`), 뒤쪽은 핏의 제작이다. 틀과 밈의 짝짓기는 [GAME_FRAME_SPEC.md](GAME_FRAME_SPEC.md), 카드 형식은 [MEME_GAME_DESIGN.md](MEME_GAME_DESIGN.md) 6절을 따른다.

## 1. 흐름

1. 조사 저장 (탐, 발굴 로직): 인기 게임과 밈 후보를 조사하고 점수와 근거를 저장한다. 밈에는 `background`(유래와 맥락)와 `reactions`(사람들 반응의 상세 요약과 출처)를 함께 저장한다.
2. 조합 선택 (탐 + 사장님): 틀 + 밈 상위 3개 조합 중 사장님이 오늘의 판을 고른다.
3. 스토리 브리프 (탐): 고른 조합과 저장된 배경·반응으로 `story_brief`를 만든다. 주인공, 상황, 반전 한 줄, 분위기 낱말, 이 판에서 웃음이 나는 지점을 담는다.
4. 카드 문구 (탐, 카드 생성기): 브리프로 두 컷(`win`/`lose`)과 공유 문구 후보 3개를 만들고, 사장님이 하나 고른다.
5. 에셋 요청 (탐 → 핏): 라이브러리에 없는 그림만 요청 목록(`asset_requests.json`)으로 넘긴다. 브리프와 출처가 함께 간다.
6. 이미지 제작 (핏): 확정된 스타일(`art/champion/README.md`)로 만든다. 나오는 대로 텔레그램에 올리고, 확정되면 확정 사유와 함께 이 저장소에 PR로 올린다.
7. 통합 (동훈 님 팀): 확정 에셋과 카드 JSON으로 오늘의 판을 배포한다.

## 2. 저장 필드 (조사 결과)

```json
{
  "name": "...",
  "background": { "summary": "유래와 맥락 상세 요약", "since": "2026-08", "sources": [{ "name": "KnowYourMeme", "url": "https://..." }] },
  "reactions": [
    { "mood": "자기비하 공감", "summary": "대표 반응 상세 요약", "where": "TikTok 댓글", "source": { "name": "...", "url": "https://..." } }
  ]
}
```

## 3. 저장 규칙

- 반응은 상세 요약만 저장한다. 원문 인용과 사용자 이름은 저장하지 않는다.
- 요약마다 출처 이름과 주소를 적는다. 핏이 작업하며 열어 볼 수 있게 하기 위해서다.
- 근거가 약한 반응은 "미확인"으로 표시한다. 링크 상태는 표시용이고, 인기 판단은 온라인과 커뮤니티 인기도로 한다.
- 원작 이미지·캐릭터·상표·음원은 에셋에 쓰지 않는다. 배경과 반응은 이야기의 재료로만 쓴다.

## 4. 스토리 브리프 예

```json
{
  "challengeId": "2026-10-24",
  "meme": "...",
  "frame": "timing_stop",
  "premise": "금요일 5시, 시계를 숨긴 사장 앞에서 퇴근 순간을 맞춘다",
  "protagonist": "사무실 직장인(새 캐릭터)",
  "twist": "너무 일찍 일어나면 들킨다",
  "mood": ["긴장", "해방감"],
  "reactionNotes": ["공감 위주 반응 요약(출처 링크)"],
  "mustAvoid": ["원작 캐릭터", "실존 인물", "상표"]
}
```

## 5. 역할과 인터페이스

- 탐: 1~5단계 코드와 데이터. 산출물은 `out/story_brief.json`, `out/card.json`, `out/asset_requests.json`.
- 핏: 6단계. 입력은 `asset_requests.json`과 `story_brief.json`. 결과는 텔레그램 시안과 확정 PR.
- 동훈 님 팀: 7단계. 입력은 확정 에셋과 `card.json`.
- 사장님: 조합 선택과 카드 문구 선택, 이미지 확정.

## 6. 남은 결정

- 조사 질문 틀에 "대표 반응 3개와 출처"를 넣는 방식(제미나이 검색 질문 형식).
- 브리프를 사람 손으로 고치는 지점(사장님이 조합을 고른 직후가 기본).
- 하루 판 제작에 걸리는 시간 목표(발굴 → 이미지 확정).
